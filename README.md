# IMPs Capital Conquest

A responsive, static, local-first Leader Command Center and Participant Field Guide, with shared searchable Knowledge Base.

## Deploy to GitHub Pages
1. Create a public repository named `imps-capital-conquest` under your GitHub account.
2. Upload **the contents of this folder** to the repository root (index.html, app.js, styles.css, sw.js, manifest.webmanifest).
3. Under **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Visit `https://YOUR_USERNAME.github.io/imps-capital-conquest/` after deployment completes.

No build step, server, or dependencies required. The same files can be hosted on Cloudflare Pages or another static host. The app caches assets for offline use after first load over HTTPS, subject to browser support. Rosters, checklists, and preferences are stored **only in the browser's localStorage**, not synced between devices; use Export CSV for roster backup. Browser storage can be cleared and is not secure storage.

**Security:** GitHub Pages public repositories are public. Do not upload confidential battle plans, personal data, or passwords. This site has no authentication. If you later need access control, migrate to a hosting service with real server-side access restrictions.

## Mechanics and evidence
All strategy guidance is distinguished from firsthand R4 observations and unverified mechanics in the Knowledge Base. Capture victory is 100% Capital progress by the 16:00 server-time deadline; no 60-minute holding rule is assumed. Battery prerequisites and cross-server teleport restrictions are not asserted as verified.
